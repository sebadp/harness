How it works

Two hooks. One config file.

Both hard gates are Claude Code hooks that exit with code 2. That's the only exit code that hard-blocks — anything else is advisory.

.claude/settings.json
{
  "enabledMcpjsonServers": ["context7"],
  "hooks": {
    "PreToolUse": [{
      "matcher": "Write",
      "hooks": [{
        "type": "command",
        "command": "bash "${CLAUDE_PROJECT_DIR}/.claude/hooks/require-plan.sh"",
        "timeout": 10
      }]
    }],
    "Stop": [{
      "matcher": "",
      "hooks": [{
        "type": "command",
        "command": "habit-hooks run",
        "timeout": 30
      }]
    }]
  }
}

Install in another repo

One prompt. Any codebase.

Paste the bootstrap prompt into a Claude Code session in the target repo. The agent explores the stack, adapts the planning-gate regex, installs habit-hooks, wires the hooks, and configures the linter thresholds.

# Step 1 — install habit-hooks in the target repo
$ uv add --dev habit-hooks
$ habit-hooks init
# Step 2 — paste the bootstrap prompt in Claude Code
